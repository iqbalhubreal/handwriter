Questions

Does my text leave my device?

No. The pages are drawn in your browser. Only the fonts and the PDF and zip libraries are loaded from public CDNs.

What does Re-roll do?

Every page is drawn from a random seed. Changing settings keeps the same seed, so the writing stays stable while you adjust it. Re-roll picks a new seed for a fresh scrawl.

How do I control page breaks?

Text moves to a new page automatically when one fills up. To break earlier, put === alone on a line, or press Insert page break in the Text tab.

Why do fonts look different at the same size?

Handwriting fonts vary a lot in letter height. Each font is scaled so that the Size slider feels comparable across them.

I can’t save a file. What now?

Saving needs permission from the page you’re viewing it in. If it isn’t available, right-click a page and save it as an image.
